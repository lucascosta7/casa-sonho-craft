# 🏡 Carlos Henrique - Seu Corretor de Imóveis para o Lar dos Sonhos

## ✨ Visão Geral do Projeto

Este é o repositório do site pessoal do **Carlos Henrique**, um corretor de imóveis dedicado a transformar a busca pelo seu novo lar em uma jornada tranquila e bem-sucedida. Desenvolvido com as mais modernas tecnologias web, este site foi cuidadosamente projetado para estabelecer uma forte marca pessoal, transmitir confiança, expertise e criar uma conexão emocional com o público-alvo. 

Fugindo dos padrões genéricos do mercado imobiliário, o site foca em **storytelling**, destacando os diferenciais do Carlos Henrique e oferecendo uma experiência de usuário envolvente e personalizada.

## 🎯 Objetivos

*   **Atrair Leads Qualificados:** Gerar interesse e contato de potenciais clientes que buscam imóveis.
*   **Fortalecer a Marca Pessoal:** Posicionar Carlos Henrique como um especialista confiável e acessível no mercado imobiliário.
*   **Experiência do Usuário Superior:** Oferecer uma navegação intuitiva, rápida e visualmente agradável, otimizada para todos os dispositivos.
*   **Foco em Conversão:** Facilitar o contato direto com o corretor através de chamadas para ação estratégicas, especialmente via WhatsApp.

## 🚀 Tecnologias Utilizadas

Este projeto foi construído com uma stack moderna e performática:

*   **Frontend Framework:** [Next.js](https://nextjs.org/) (com App Router) - Para renderização rápida e otimização de SEO.
*   **Estilização:** [Tailwind CSS](https://tailwindcss.com/) - Para um desenvolvimento de UI ágil e responsivo.
*   **Linguagem:** [TypeScript](https://www.typescriptlang.org/) - Para maior segurança e escalabilidade do código.
*   **Animações:** [Framer Motion](https://www.framer.com/motion/) ou [AOS (Animate On Scroll)](https://michalsnik.github.io/aos/) - Para transições suaves e elementos dinâmicos que enriquecem a experiência.

## 🎨 Design e Experiência do Usuário (UX/UI)

O design do site é uma fusão de elegância e funcionalidade, inspirado na identidade visual do Carlos Henrique:

*   **Paleta de Cores:** Uma combinação sofisticada de **Azul Marinho Escuro** (para solidez e confiança), **Dourado/Amarelo Vibrante** (para luxo e energia) e **Branco/Off-white** (para clareza e legibilidade).
*   **Tipografia:** Uma combinação harmoniosa de fontes serifadas elegantes para títulos (ex: Playfair Display, Lora) e fontes sans-serif limpas para o corpo do texto (ex: Montserrat, Poppins, Inter), garantindo profissionalismo e acolhimento.
*   **Responsividade:** Layout 100% adaptável a desktops, tablets e smartphones, garantindo uma experiência impecável em qualquer tela.
*   **Foco na Conexão Pessoal:** Elementos visuais e textuais que destacam a personalidade e os diferenciais do Carlos Henrique, construindo confiança com o visitante.
*   **Logo e Favicon:** A logo do Carlos Henrique será o elemento central da identidade visual, presente no cabeçalho e como ícone do site.

## 🌟 Funcionalidades Principais

### 1. Hero Section Impactante
*   Título e subtítulo persuasivos: "Seu novo LAR TE ESPERA! Conforto, praticidade e qualidade de vida em um só lugar."
*   Destaques visuais dos benefícios: Proximidade à Estação Itaquera, Vaga de Carro, Varanda, Lazer de Clube, Documentação Grátis.
*   CTA principal para iniciar a busca pelo imóvel ideal.

### 2. Sobre Mim: Conheça o Carlos Henrique
*   Uma seção dedicada a apresentar o corretor, sua trajetória, paixão pelo mercado imobiliário e seus valores (Conforto, Segurança, Qualidade de Vida).
*   Diferenciais pessoais como iniciativa, proatividade, ética, foco em resultados e habilidades interpessoais.

### 3. Imóveis em Destaque
*   Carrossel ou grid de imóveis selecionados (placeholders), com fotos de alta qualidade, descrição breve e CTA para detalhes ou contato.

### 4. Diferenciais do Imóvel
*   Detalhes dos benefícios dos imóveis oferecidos, como proximidade a pontos chave, comodidades e facilidades.

### 5. Depoimentos e Histórias de Sucesso
*   Carrossel de depoimentos de clientes satisfeitos (placeholders), construindo prova social e credibilidade.

### 6. Contato Facilitado
*   Formulário de contato direto, informações de WhatsApp, telefone e e-mail.
*   Links para redes sociais e mapa de localização (se aplicável).

### 7. Botão Flutuante de WhatsApp
*   Um CTA persistente e de fácil acesso para contato imediato com o Carlos Henrique.

## 🛠️ Como Rodar o Projeto Localmente

Para configurar e rodar este projeto em sua máquina local, siga os passos abaixo:

1.  **Clone o repositório:**
    ```bash
    git clone [[URL_DO_REPOSITORIO]](https://github.com/lucascosta7/casa-sonho-craft.git)
    cd casa-sonho-craft
    ```

2.  **Instale as dependências:**
    ```bash
    npm install
    # ou
    yarn install
    ```

3.  **Configure as variáveis de ambiente:**
    Crie um arquivo `.env.local` na raiz do projeto e adicione as variáveis de ambiente necessárias (se houver, como chaves de API para serviços externos).

4.  **Inicie o servidor de desenvolvimento:**
    ```bash
    npm run dev
    # ou
    yarn dev
    ```

    O site estará disponível em `http://localhost:3000`.

## 🌐 Deploy

Este projeto está configurado para um deploy fácil na Vercel. Basta conectar seu repositório GitHub à Vercel e configurar as variáveis de ambiente, se necessário.
